# 街区走访与持续展陈证据

日期：2026-09-29。范围见[阶段验收](../../2026-09-29_C3c街区走访与持续展陈验收.md)。

- market/seaside/lin-qiao-seaside-conversation：两位居民实际走到相应地点的存档恢复，进入同一交谈界面取证。固定复核相机，不是玩家原镜头录像。
- wall-exhibition/reading与album-exhibition/reading：两条连续真实输入路线（含主动休息一天和步行回访）的最终结果；不是将状态夹具冒充完成路线。
- city-map：最终完成后的公共活动导航入口。
- counterexample-wall-small-text：首版字号过小反例。后来分开标题/正文，并隐藏与展板重叠的浮动标签。
- route-interview_hr/defend/handover：后台双公司完整职业路线的3个节点，原职业流程仍可继续。
- render.json：8张支线最终图以及最小化/不可聚焦/无焦点/鼠标可见守卫。最终8张、3张职业图和1张反例均实际查看。
- validation.json：命令结果摘要与日志SHA-256；包含实际两位带路人的里程、道路、控制器侧绕真实行人的诊断。全套/后续专项范围详见验收表。
- build-manifest/artifact-sha256：提交前真实构建身份；image-sha256覆盖所有归档图片。

图片仍能看到重复人物/建筑、简单材料与通用手势。本阶段没有正式视听签收、正常游玩帧率或完整城区体验完成的结论。
