# S1 双公司场景工程证据

全部文件来自本轮实际运行，父级 S1 美术关卡与双公司品质版仍开放。

- `a/b-*.png`：修复椅脚后的 12 张定点图，Compatibility，1280×800、FOV 65、游戏约09:00—09:01。entry 是玩家正常镜头，其余独立Camera3D。曝光/光照沿用项目，机位精确值见 `tools/capture_company_spaces.gd`。六机位×两公司不等于计划的12比较主题，不含完整连续录像。
- `s1-final-source.json`：这些图与性能的运行时摘要 `867f180d98ea101d30d0658e3ed86234c696601b9f0a167b1260c3057de16084`，基于01a9764、包含未提交场景修改。之后鼠标修复9234a4a不在这些旧图/性能输入内，不能称为最新包同一身份。
- [性能表](performance-table.md)及四份`verified-perf` JSON：两个渲染器、两个公司、三轮普通/混乱、每情景600帧。全部14,400样本记录实际绘制增量。GPU计时不可用，长测/最终分辨率/最终资产密度未验收。
- `s1-no-render-rejection.json`：故意禁渲染的反例被标无效，工具退出3；不得把其中循环速度作为渲染FPS。
- `build-manifest.json`、`artifact-sha256.json`、`package-menu.png`：场景修复后、鼠标修复前的历史包，项目外图形与源码目录headless均通过。**该旧包仍含自动捕获逻辑，不作为本轮推荐启动包。** 新无自动捕获包另记在`pointer-safe-build-manifest.json`。
- `checks.json`：定向修复、全套检查与未完成图形路线的摘要。原`logs/s1-*.log`保留本地诊断；完整职业图形路线在跟随修复后、椅脚修复前通过。椅脚修复后的图形路线因用户反馈抢鼠标而中断，只到A备用投影，未记通过；当前headless完整路线随50项回归通过。

当前已观察问题：玻璃仍缺真实透明反射、家具边缘/植物/人物细节粗；A/B风格和天花空间已有区别，但不能以新PBR或测试通过折算为GTA VI水准。正式参照校准、12主题、带声音连续游玩、用户/独立玩家签收仍未完成。

历史采样曾使用置顶参数；用户明确纠正后已停止，后续自动验证不得置顶、拉前台或捕获鼠标。此次源码和记录提交不启动任何游戏窗口。
