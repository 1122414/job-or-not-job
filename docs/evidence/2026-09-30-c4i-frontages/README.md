## 真实动态问题

`navigation-diagnosis.json`保留失败日志摘要、原触发和最终专项数值：中心路口的静态通路检查通过并不能排除动态回拉；过街门禁正确排空也不能排除对向行人自己锁死。最终分别由走廊判断、沿过街轴的分侧控制解决，不关闭碰撞、不传送、不移动玩家、不强制清空占用。

四路口专项起始为已进入过街的两人和到期行人放行阶段，保持真实胶囊和车流；冻结公交预置远离测试路口，避免它另行堵住办公室出口。自然晚间周期另保留全部实际公交/车流/居民，三同事各两地及返程通过。完整90项回归已通过，逐日志摘要、测试源码与时序检查见`verification.json`，不存在ERROR/WARNING。

四项CC0、39,372,539字节原件和制作限制见[来源与重建](../../../production/environment/polyhaven_street/README.md)。保留源alpha与真实压缩不等于实现完整玻璃透射，也不等于正式美术、独立玩家或GTA品质验收。
