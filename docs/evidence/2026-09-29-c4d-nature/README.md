- `walk/`4图：真实移动输入从中心轴走向滨水，使用玩家原镜头，居民/车流/时间运行；71.7505m、09:00→09:07，`walk.json`保存位置与绘制采样。截图只记录若干时刻，没有冒充连续录像或正常FPS。

`mesh-rebuild.json`比较独立重建的所有网格通道和索引；`.res`容器字节并不相同，未宣称完全相同文件。`verification.json`保存74项Godot/28项Python与定向检查摘要；`artifact-verification.json`保存独立包的源/包身份、签名、CRC与两目录启动结果。
