# 原对话框内嵌自由输入

`runtime/`是源码实机，`packaged/`是本轮最终独立包。`tools/capture_inline_chat.gd`生成正常/输入中/回复/长回复/1280×720五种状态；每次断言输入和选项矩形在视口内且不重叠，最小化无焦点、独立SubViewport、persistence=false。回复文字是明确标注的固定界面夹具，不是云端生成。

`tests.json`记录12项定向回归及最终GUI复验。初次GUI点击使用了错误的窗口坐标域，改用视口内坐标后真实发送、取消与固定选择通过；超时在请求启动前配置。没有通过删断言或改成直接emit pressed掩盖点击失败。

本轮未读取用户运行进程密钥，未改变存档schema，未自动结束玩家游戏。Metal退出既有7 Texture RID警告保持。详细问题与测试见[验收](../../2026-10-09_对话框内嵌自由输入验收.md)。
