# C4h 中心街段建筑证据

对应[验收记录](../../2026-09-30_C4h中心街段建筑制作验收.md)。before-source来自已验证C3h最终源码，提交标签保持原记录；本阶段变更前没有运行代码改动，11视角先行实拍，不把旧manifest称为本次新生成。final-source对应本阶段固定运行源码；制作工具与测试夹具的修正另有说明。

- `before/`：11个1440×900原立面视角及真实绘制计数。
- `modules/`：三种真实模块的正面/斜面6图，窗后独立背墙用于检查透明和深度。
- `iteration/`：首版隔墙共面闪烁三张代表图，不作为最终版本；完整11视角计数保留在render.json。
- `after/`：11个同位最终视角、606组实际GPU缓冲及23树位重建确定性。
- `walk/`：连续玩家输入、原相机、263.358069m和15路点；7原图。
- `career/`：后台双公司完整路线7图；状态检查和艺术品质分别判断。
- `cost-comparison.json`：同位调用和三角数前后比较；增加30,758,376字节压缩纹理数据。不包含普通FPS结论。

- `package/`：实际独立包从项目外启动，默认Metal三张昼夜图和运行身份。
- `package-identity.json`：签名、ZIP CRC、内外清单、运行源码/PCK/输入引擎及签名后引擎摘要核对。

归档48张原图，25张实际查看；最终街景11张全部查看，其他明确标记，详见`image-sha256.json`。图片不经后期修改。`verification.json`保存最终85项Godot测试/日志摘要、30项Python和图形/两目录包的成功依据；全部最终检查无ERROR/WARNING。全部图形工作最小化、不可聚焦、鼠标可见、禁根输入、Dummy音频，不写玩家档。
