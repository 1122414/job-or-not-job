# 网页试玩导出记录

范围：当前内容的电脑浏览器试玩包。本次不是公网发布，也不是完整网页玩法验收。
构建：Godot 4.7.1，Compatibility，单线程，未启用 PWA。2026-09-22 15:21 本地构建快照；并行开发随后继续修改游戏内容，ZIP 不代表之后的工作区。

## 使用

安装与引擎匹配的 `web_nothreads_release.zip` / `web_nothreads_debug.zip` 官方模板后，执行 `sh tools/package_web.sh`。
产物：`build/web/index.html` 及配套文件；`build/今天不上班-web.zip`，约59 MiB。
本地启动：`python3 -m http.server 8060 --bind 127.0.0.1 --directory build/web`，浏览器打开 http://127.0.0.1:8060/ 。不能直接双击 HTML。
点击“继续游戏”开始；Esc打开菜单，网页优先使用菜单保存，避免F5刷新。存档属于当前站点和浏览器，不与桌面存档共享。完整持久化尚待验证。
对外分享需将ZIP全部内容部署到HTTPS静态站点，保留文件名与许可文件；本次未选择或发布站点。

ZIP SHA256：`7daad38201cdc53d844fb7efcf9336891943cf11688ad362636332736ac093c6`。
