# 时间驱动表现必须覆盖暂停恢复与日内周期

信号：正常时间流逝时灯光正确，但暂停切换时间或读取夜间存档后仍保持白天；第二天以后一直亮灯。

机制：表现仅放在物理帧更新，暂停时不运行；绝对分钟直接与06:00/18:00比较，跨日后把全部时刻当作夜间。这是两个独立边界，需要分别验证。

处理：复用已有的集中时间表现入口main.update_daylight，让读档、时间变更及正常帧走相同路径；昼夜使用payroll.minute % Payroll.DAY，职业约定等绝对时间仍保持原语义，不全局改成日内时间。

支持案例：C4j公交舱灯和车头灯。暂停切到20:00、恢复夜间JSON原检查实际两项失败；跨日问题先由源码识别。修正后tests/city_bus_visual_test.gd覆盖第1/2/7天05:59、06:00、09:00、17:59、18:00、23:59共18点，以及暂停读档。最终图形在paused=true且不手动设公交灯的条件下得到夜间车厢图。

验证状态：本项目验证一次。适用于已有绝对游戏分钟和固定每日开关边界；不能推广为天气、季节日照、营业日历或独立供电模拟。正式性能和视听评价独立验收。
