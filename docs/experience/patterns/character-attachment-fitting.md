# 附件几何外插、蒙皮与形变贴合分开验证

信号：GLB可导入，但鞋边出现碎片、衣物穿插、眉部尖角；单表情端点正常，中间权重仍破面。本记录适用于hm08及本项目MHCLO转换，不是任意人物的通用碰撞算法。

机制与处理：

- MHCLO的负重心系数用于几何外插，不能原样成为骨骼蒙皮权重。保留顶点坐标外插；只累加正的蒙皮贡献，再做四骨选择/归一化。v2实际GLB有904个负值，v8为0。历史上默认转换曾保留兼容，旧三GLB并未同步修复；2026-09-30 CH1-A已另行修复并启用默认构建入口的positive_skin。
- 服装delete_verts不仅影响人体，还应按z_depth传递到下层衣物。主角白色裤脚的平涂诊断归属鞋袜；被裤子完整覆盖的220个鞋袜面剔除后消失。边界面不可按“有一个点隐藏”全删。
- 分别贴合中性/目标眉形，线性中间值仍可能越过皮肤三角形；只检查顶点也会漏掉面心。细分后绑定同一皮肤三角形，深皱眉局部包络避让，再检查导出的GLB顶点、边中点、面心及43状态。最终最小间距为0.470/0.133/0.549mm。增加间距有浮片/阴影风险，不能无限抬高眉毛。
- UV矩形可与相邻岛局部重叠。口腔初版筛选误把手的边缘当口腔；完整UV连通岛可以排除。口腔射线可能穿过张嘴空洞落到后脑，需限制局部距离并保留唇缘；本项目阈值不能直接套另一种拓扑或极端脸型。
- 形变位置变化时同步重算NORMAL delta；“存在形变”不代表光照随表情正确。

诊断先用平涂区分网格归属，再读原文件/实际导出数据；同位图片与数值相互补充。不要用CC0、骨骼名一致、头部AABB或旧人物动作测试替代新体型接受条件。

验证状态：本项目同一轮三人验证一次；有限表情采样，不是全组合、骨骼动态或所有脸型证明。支持案例与返工证据见`docs/2026-09-29_S2人物形变与衣装缺陷修复验收.md`；检查工具`tools/check_character_fitting.py`、`tools/inspect_character_candidates.gd`，针对性测试`tests/test_character_builder.py`。仍开放发边、材质、各体型动作、LOD及运行时接入。
