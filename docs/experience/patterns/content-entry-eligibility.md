# 内容入口与叙事资格

适用信号：旧内容和单模块测试都存在，新角色却缺少正常进入路径；新剧情取消了某个身份，而旧内容要求该身份。

机制：内容内部可运行与玩家从当前剧情获得参与资格是不同条件。直接构造旧职业状态的测试，不能证明新角色能进入同一内容。

本项目案例（2026-10-09，NEXT02）：`scripts/autumn_story.gd:offer`明确拒绝B录用；`scripts/dialogue.gd:b_friend`及`scripts/work_projects.gd:open`要求B雇员。`tests/autumn_career_test.gd`验证新主线不能通过B获得工作；`tests/work_projects_test.gd`在测试分支直接构造B任职来验证原交接。两者各自正确，但不能据此宣称新玩家能体验B交接多解。

诊断：分别检查新游戏入口、身份/权限前置、事件启动、参与者、成果归属、结束与存档，不仅搜索有没有相关台词或动作。处理候选是复用为朋友自愿事件，由在职者执行工作提交；不是直接删除权限检查。是否采用仍待设计确认与原型。

适用边界：B取消录用是已确认剧情，不是要修成可以入职的缺陷；仅确认该多解内容入口受限，不意味着阿乐无法交谈、所有生活内容都不可达或整个主线卡死。

验证状态：代码交叉检查一次；未实现新入口，未做自然玩家到场验证。执行复核及边界见[核心体验计划](../../2026-10-09_核心体验复核与后续开发计划.md)。
