# 人物比例变化必须重验运动与物理支撑

信号：新人物骨名相同、所有变换有限，脚却滑动/悬空；模型比碰撞体短；待机通过但坐持没有检查。

机制：名字与骨架拓扑并不保证骨段长度相同。固定步幅搭配旧髋高会让两骨求解目标不可达，距离clamp在数值上保持合法却缩短支撑轨迹，产生滑步。固定坐姿角度也会随小腿长度变化改变脚高；固定1.8m胶囊继续托住短人物上方的物件。

处理：不同目标GLB各自烘焙并记录源/目标摘要；用实测骨段限制髋高，保持世界速度与步幅关系；坐姿同时约束髋高和脚踝站立高度。NPC站/坐/倒地碰撞按模型高度更新，刚体物件要在姿势变化时唤醒。动画混合与支撑分别验证，不能用有限矩阵代替接触验证。

案例：2026-09-29林岚走/跑15.8/17.6mm滑移→最终513点采样最大2.04mm，坐姿脚高误差53.6mm→小于0.001mm，1.8m胶囊→约1.5869m。`tests/gait_test.gd`、`seating_test.gd`、`body_support_test.gd`及`authored_motion_test.gd`覆盖三旧衣装与三新人物。最终53项全套通过；见`docs/2026-09-29_S2三关键人物运行时适配验收.md`。

边界：验证一次，只证明本项目平地、固定座面和既有动作。没有楼梯足底IK、任意座椅、手指包覆或全身碰撞结论。骨骼测试不能发现衣装尖片，仍需真实蒙皮采样与动态图片。

相关边界：`game.speaker`同时可能是NPC与工位。新增注视接口先检查对象类型，否则类型错误会提前终止玩家物理帧，表现为无法移动离开对话。`interaction_test.gd`实际抓到该回归并验证修复；视线是表现层，不应阻断物件交互。

采样反例：初次33点与生成的33键重合，显示接近零漂移；扩至129点后才发现帧间插值仍滑11.6mm。根与腿轨道增至129键、其他轨道保留33键，再以513点覆盖每段插值，最终2.04mm。检查点必须独立于实现采样，不能把关键帧正确当作连续运动正确；旧三衣装跑步513点约10.19mm仍在历史12mm阈值内，S4更严格出口保持开放。

2026-09-30 S4b：移动片段切换需保留步态周期，单个片段的脚部支撑通过并不能发现切换重起。六体型、walk/run/carry四种切换、五个非整周期位置，旧实现120次全部回到0；播放新片段后在正常混合前seek到原归一相位，专项120次误差为0。走跑上身接入Quaternius后，以源左脚前伸事件对齐目标左脚前伸，不把源秒数直接套进1秒目标步态。保留各体型原腿部/根高度轨道，在67点独立采样中支撑位置与原实现一致，另由513点gait_test核查帧间漂移。此结论已专项验证一次；不证明起停、转身、坡地、脚掌滚动或衣装碰撞达到正式品质。原裙装在前后同相位图中仍有拉伸/局部露肤，不能以新摆臂已接入关闭服装制作。
