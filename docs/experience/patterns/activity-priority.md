# 私人活动与任务跟随的目标优先级

信号：同事清醒、导航有路、无伤病，却停在原地，职业协商提示等同事到场。

机制：`SocialLife.npc_target` 为待回复/同行约定提供原地或私人目的地，覆盖 `npc.gd` 的 B 协商跟随。场景路线时机变化会触发邀请，暴露既有冲突，并不必然是新家具堵路。

诊断：同时检查人物状态、navigation route、onboarding阶段、社交目标与career阶段；先证明路线是否存在，再调整碰撞。不要删除私人约定或放宽协商距离掩盖问题。
