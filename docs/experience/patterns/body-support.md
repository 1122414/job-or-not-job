# 姿态与碰撞支撑不一致

信号：键盘停在约 1.85m 高，附近 NPC 已倒地；新世界桌面静置检查却通过。
机制：NPC 使用站立长方体，视觉坐下或倒地时碰撞体未改变。边角超出人体外观，物品还可能在旧支撑面休眠。
诊断：比较旧存档物品与 NPC 相对位置，以同样偏移构造真实物理测试；先验证站立顶部接触，再让人物倒地，避免测试物品原本已掉落的假阳性。
处理：`scripts/npc.gd` 使用胶囊，并随站立、坐下、倒地更新形状高度与位置；姿态改变时唤醒附近未冻结道具。
验证一次：`tests/body_support_test.gd` 修复前倒地后键盘仍高 1.846m；修复后约 0.050m，边角场景也落地；16 项回归通过。
边界：这是近似身体碰撞，不是布娃娃；不证明全部道具悬空均由此引起，也不证明姿态动画自然。玩家控制器及复杂堆叠需各自验证。
