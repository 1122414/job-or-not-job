# 姿态与碰撞支撑不一致

信号：键盘停在约 1.85m 高，附近 NPC 已倒地；新世界桌面静置检查却通过。
机制：NPC 使用站立长方体，视觉坐下或倒地时碰撞体未改变。边角超出人体外观，物品还可能在旧支撑面休眠。
诊断：比较旧存档物品与 NPC 相对位置，以同样偏移构造真实物理测试；先验证站立顶部接触，再让人物倒地，避免测试物品原本已掉落的假阳性。
处理：`scripts/npc.gd` 使用胶囊，并随站立、坐下、倒地更新形状高度与位置；姿态改变时唤醒附近未冻结道具。
验证一次：`tests/body_support_test.gd` 修复前倒地后键盘仍高 1.846m；修复后约 0.050m，边角场景也落地；16 项回归通过。
边界：这是近似身体碰撞，不是布娃娃；不证明全部道具悬空均由此引起，也不证明姿态动画自然。玩家控制器及复杂堆叠需各自验证。

2026-09-21 补充：仅旋转根节点并暂停当前骨骼动画，会把坐姿或出拳横放。新增固定倒地动画，停止继承受击瞬间姿势；胶囊仍为近似碰撞，并非真实布娃娃。死亡有独立 hp/dead 字段和存档校验，旧档缺失时按存活迁移。

2026-09-22 全项阶段2：仅减小根节点y不足以修正坐姿。实测模型髋约0.917m，坐姿需要同时匹配座高、膝弯、桌高和键盘距离。新增三套骨架几何检查 seating_test。椅背恢复碰撞后，原1m高的交谈射线被椅背遮住；改到1.35m起点/1.2m人物目标后 interaction_test 恢复通过。起身空间查询须留出地面余量，默认shape margin会把地板误判为四个候选方向都被堵。验证一次，适用于当前MakeHuman骨架，不推广为其他资产固定数值。

2026-09-22阶段6：加长idle/walk/strike交叉淡入后，连续走路→挥击→倒地在visual_test出现腿部残留。倒地停止旧动画混合后播放专用姿态，根节点旋转负责倾倒过渡；三套人物回归通过。此处理仅用于当前程序动画倒地，不是通用布娃娃替代。
