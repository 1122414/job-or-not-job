# 独立枝叶的减面与连通性

适用信号：树木自动LOD后明显变秃，或整体轮廓尚在但个别叶柄断成两段；总三角形下降却无法满足远景成本。

机制：树冠由大量独立小片组成。整体几何误差驱动的自动减面可能直接删掉这些小片；对单个连通分组减面，也不保证结果仍连通。几何厚薄不能单独判断片状/管状：裸枝也可由带透明裁切的曲面表现。

2026-09-29 C4d案例：Poly Haven `tree_small_02`原始2,062,487三角形；全局自动减到245,964/64,027时，实际同位图出现大面积叶片丢失，拒收。原叶材质面有30,250个连接分组。首版逐组处理仍在LOD0出现30,718组；确认所有466,431顶点均被引用，排除了“遗留未引用顶点”猜测。按源组检查后定位到468个42顶点叶柄，其12三角形自动LOD分为两段；跳过不连通候选后，三级输出均恢复30,250组。精确位置焊接曾尝试且无改善，不能将本例归因于切线接缝。

71顶点类型未减掉的168,153三角形来自2,437张裸枝裁切片。离屏形状和法线一致性核查后归入曲面片，采用UV轮廓简化。源组位置保留，近档有曲面中心，中远档减少内部几何；叶柄候选要求连通。结果全树297,834/160,239/100,716三角形。整城预算仍待验证，不能仅凭比原件少就判定成本合格。

诊断与处理：

1. 保存原件与校验；按索引计算源连接分组，核对分组内的真实几何/UV/材质。
2. 对每组记录LOD前后连通数，保留被拒绝候选，避免只看全树总面数。
3. 检查顶点引用、法线/UV/切线通道及统一地面锚点；改变拓扑后重新生成切线。
4. 用原件/派生物同视角图检查轮廓、冠层密度；实际运行距离往返扫描防止范围重叠或空档。
5. 独立重建比较全部顶点通道及索引的摘要。压缩资源容器SHA可不同；本例几何摘要逐字节一致，容器差异的具体字段未进一步定位。

验证状态：本资产验证一次。`tests/city_nature_test.gd`验证三级连通、引用、尺寸和真实纹理；`tools/bake_city_tree.gd --compare=...`验证重建几何；`tools/verify_tree_lods.gd`在7—48m往返330个真实绘制采样中无整树消失或重叠。固定拓扑分类只适用于已校验源文件，不适用于任意树。静态截图、索引一致和LOD范围检查都不等于无感过渡、风动画或最终视听签收。
