# 特殊剧情人物与异步自由对话边界

适用信号：普通居民会倒地，但导师只打印受击台词；模型等候时取消卡住；迟到回复污染读档后的关系。

机制与处理：导师原为AutumnStoryPoint/StaticBody，不走OfficeNPC健康和动作链。不能以普通NPC的打击通过推断导师也通过；新增实际移动、健康、昏迷恢复、关系及保存，`tests/npc_feedback_test.gd`通过真实玩家接触检查导师和四种动作。其他装饰人物/司机不因此自动获得完整交互。

HTTP使用进程常驻的HTTPRequest，但世界在输入框聚焦时暂停（原整页入口已按U01用户反馈撤换）；请求附serial和restore_revision，取消/切页/读档使旧token失效。服务回答严格白名单JSON、关系增量范围和每日次数；模型文字不成为职业/剧情命令，固定选项始终可回退。`tests/free_chat_test.gd`本机TCP协议夹具覆盖成功、坏格式、401、超时、取消/读档迟到、重复发送、额外命令、数值和长度越界。无真实API密钥时不把固定回复画面标成云端回答。

实测反例：本机Godot4.7.1中use_threads=true请求遇到测试服务不回包，cancel_request调用停住；使用默认非线程事件循环后，超时和取消均返回。只确认这个版本与夹具，不泛化为所有Godot线程请求必死锁。JSON.parse_string坏格式会打日志错误，改JSON实例parse返回错误码，在UI显示可回退提示，不输出服务正文。

验证状态：定向测试与源画面验证一次；真实DeepSeek账号请求、中文IME、跨设备及自然交谈体验未验收。

U01界面上下文修正：独立“我想自己说”页虽通过协议测试，用户实际要的是正常对话框内的附加输入。模型返回文字与固定选择数据分离，request同时校验原speaker和conversation上下文；固定选项推进前取消请求，避免同一个NPC的新分支被旧回答覆盖。当前台词也加入模型现场资料。新增实际按钮和输入回归通过，协议/存档格式保持，单有HTTP成功不能当作对话入口符合用户意图。
