# 程序化地表细节与像素足迹

信号：近处砖缝正常，远处同样的缝宽形成点线/斑纹；打开 MSAA 后仍能在材质内部看到混叠。代码导入和逻辑回归均不能发现这个问题。

机制：直接按世界坐标用固定 smoothstep 宽度绘制毫米级砖缝，没有考虑一个屏幕像素覆盖的世界面积。MSAA 主要处理多边形边缘，不会自动过滤任意程序化材质中的高频图案。

诊断与处理：先固定相机、时间、分辨率，保存失败原图；按 fwidth 估计砖缝的像素足迹，扩大远距平滑范围，并衰减高频颗粒。材质统一使用世界坐标，避免每个实例缩放改变砖尺寸。见 assets/materials/city_paving.gdshader、city_grass.gdshader。

案例：2026-09-29 C4a 老城/滨水八视角，证据 docs/evidence/2026-09-29-c4a-streetscape/iteration-paving-aliasing.png 与 after-old-street.png。初版点状砖缝经修正后连续，静态同位对比验证一次。

边界：不适用于所有透明叶片、阴影或模型锯齿；本次没有正常操作的移动镜头录像，不据此宣称完全消除时间域闪烁。最终场景性能与品质仍需独立验收。
