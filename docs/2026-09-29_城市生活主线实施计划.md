## C1：连通区域与公交闭环（当前工程阶段）

计划功能：保留双公司，打开街区；连通老城街口、住宅入口、滨水公共步道；一条实际运行的环线、四站、上下车与主动跳过等车；地图/导航、区域识别、到访记录；乘车状态存读档。新增环境先验证道路、空间比例和交通，明确不是最终写实资产。

计划修复：旧小地图不能表达公司外位置；公司位置判断把远处区域误当公司；新交通不能穿过行人/障碍或在行驶中把玩家扔下；恢复乘车不得被旧位置修复逻辑移出车辆。

验收条件（实施前定义）：

- G01：玩家实走穿过旧边界抵达四站；公交自然完成整环并逐站停靠；真实输入登乘/请求下车/下车，暂停不走，车外阻挡会停车。
- G01/G06：乘车中 JSON 写读/恢复保持车辆、乘客、方向与唯一物品；旧 v1—v11 可读；坏线路/站点/非有限数/越界状态拒绝且不修改当前世界。
- G01：地图实际 Control 可鼠标/焦点选择，导航能到站，恢复游戏不捕获鼠标。
- 既有完整 A/B 路线、库存/存档、页面/鼠标、全部项目检查通过；隐藏不可聚焦视口看城区、站台、乘车和地图；独立包可启动。

阶段开始时的观察：只读确认边界、站棚、固定导航、v11 存档、鼠标主动点击规则。

2026-09-29 观察进展：C1 工程完成；56 项 Godot 和 24 项 Python 通过，实走四区、482.2296m 自然公交整环、真实键鼠、乘车 JSON/旧档、站台阻挡、隐藏双公司图形路线及独立包两目录验证通过。9 张最终城市图和 2 张诊断反例已复核。详见 [C1 验收](2026-09-29_C1连通城区与公交验收.md)。最终美术和独立玩家未验收。

未完成：驾驶、其他车辆与交通秩序、公共居民、分区加载/区域导航/整城坐标迁移、城市事件内容、正式美术/混音/性能、独立玩家验收。C1 不代表 G01 或 P4 完成。
