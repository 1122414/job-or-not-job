## 范围与制作选择

现有 101 公交只有方盒侧板、立柱、圆柱轮胎和方形座位，缺少玻璃、驾驶区、轮拱与连续车门动作。C2c 同乘图像已直接看到这些缺口。本阶段制作适配现有七米车体的原创社区环线公交，保留现有外部碰撞、六座布局、乘客身份、行驶路线和存档 v23。

按项目现有 Godot 制作流程离线生成带圆角的车身、窗口、独立轮组、车厢和门组件；运行只加载生成资源。先检查开放资产候选：Poly Haven 公共 API 本次返回 HTTP 403；MrJaneLAB 低模轿车不覆盖公交及近景内饰；Khronos CarConcept 是概念跑车；OpenGameAsset 的免费下载页面没有可核实的开放许可，不接入。未下载第三方车辆、未安装依赖或购买资产。原创几何不代表正式写实车辆已经达标。
