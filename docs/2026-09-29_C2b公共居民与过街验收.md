# C2b 公共居民与过街验收

日期：2026-09-29。源码基线630ef32，实施提交见本阶段Git，提交后补充标识。当前是工程子阶段，完整G01—G06和64km²都市圈目标继续开放。

## 玩家可以做什么

首区新增12位稳定居民，使用共享时钟选择早、午、晚、夜间目的地，沿公共步道路网实际走到书屋门口、社区、广场和海边，停留后继续活动。近处E交谈、数字键回应，告别后恢复行程。三处斑马线协调公交、通行车和居民，行人先等车辆清空，过街后给车辆留出通行窗口。

玩家攻击、投掷物件和驾驶撞击接入居民后果。居民记住交谈、受伤和目击危险，附近目击者避险；普通攻击最多倒地，约12秒后恢复，死亡不随读档复活。现有职业NPC救助流程保留，公共居民尚未接入完整救助/现场处置。v14保存居民身份、路线、当前位置、记忆和过街时钟，旧v1—v13初始化新增居民并保留原进度。

## 边界和接续

固定首区的居民活动、单向交通与简化记忆，不代表完整城市生活。居民仍复用三套原型资源，建筑多为外壳，目的地停留没有完整场所活动/营业内容；公交乘客、双向路口规则、公共救助、车辆损伤/正式手感、分区加载和远近分层模拟尚未完成。按当前占用和死亡逻辑推断，致命伤害留在斑马线上时会持续阻挡该过街点（完整现场处置未动态验收），现场处置和绕行仍需后续接入，不能隐藏死亡事实来伪装恢复。

图形与逻辑通过不证明最终人群密度、声音、美术、20分钟双画质性能或独立玩家验收。后续主线仍为公共场所和多解城市事件、分区能力、整体视听样板，验证后扩建八类城区。
