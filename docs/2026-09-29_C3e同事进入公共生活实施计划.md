# C3e 同事进入公共生活实施计划

日期：2026-09-29。基线 main / 3c79f6c。完整 G01—G06、64km²都市圈/16km²密集城区、GTA VI展示视听及正式性能/玩家关卡保持开放。

## 交付目的

让职业中认识的人能走出办公室，与玩家进入书屋、花园、滨水步道，形成可中断、可恢复并影响后续交流的共同经历。作为完整城区生活的一部分，不以单条同行或状态测试替代30—60分钟自由体验。

## 事前验收

1. 两公司人物从真实工作/下班位置走至三处地点并返程；记录累计移动与逐帧最大位移，不以传送代替路线。穿越滨水路口与真实公交、车流同时运行，许可/清空后恢复；途中落后只在路边等待。
2. 地点选择、到场、离场/隔墙/车内/受伤不可远程结算；暂停、恢复、拒绝、书屋闭馆、工作协商/面试/带领优先与旧茶水/午饭回归。
3. 三种回应产生不同记忆与下次对话，重复不能刷奖励；原雇佣、工资、工作成果不由私人同行伪造。
4. 实际磁盘写读与独立进程恢复同行；新字段坏档全部拒绝且世界不部分应用；v1—v18保持兼容。
5. 项目全套、后台两公司完整职业、真实图形同行及正常玩家镜头图片复核；根窗口初始化和deferred均最小化/不可聚焦、禁根输入、鼠标可见。独立包两目录/签名/CRC/源码身份验证。
6. 中文实施提交、项目/Obsidian实测记录与校验和同步。没有证据的正式表演、全城交通、长时间性能和玩家体验继续开放。
