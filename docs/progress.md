## Phase 01

动作实现及引擎验证通过：`tests/action_test.gd` 检查单次命中、倒地恢复、小件投掷、大件不可拿起、物件出界恢复，0 失败。桌子旋转掀翻、椅子推撞、打印机预制损坏、键盘较长触及范围已接入。实际 macOS 窗口观察角色、镜头、道具，执行移动、跳跃与释放鼠标；手感尚需完整试玩评价，不宣称“好玩”。

用户追加 UI 方向：参考 GTA 的左下圆形地图/生命条、右上冲突星级、底部短提示。冲突仍按公司隔离，无警察或跨公司声誉扩展。

## Phase 02

小件背包不设容量，Q 收纳、R 轮换、Tab 查看，切换自动收纳旧手持。真实 NPC 反击每秒造成 18 伤害，死亡等待 2 秒、附近安全点恢复、保护 5 秒。`inventory_test.gd` 验证物品唯一位置、背包打开死亡、连续伤害保护、投出后死亡不补回、堵塞安全点替换；自动检查通过。存读档联测留到 Phase 07。

## Phase 03

连续街区、两个开放入口、10 位职务人物、局部可见性反应与靠近信息已实现；GTA 式圆形街图、生命条、星级位置和精简提示已落地。`world_test.gd` 实际移动穿过两家入口和连接街道通过；动作、背包回归通过。macOS 窗口确认 HUD 与街区显示。入口地面高度差导致阻挡，已统一碰撞面修复，记录于经验索引。第二家公司职业内容尚未接入，不据此称完整 MVP。

## Phase 04

`career_test.gd` 覆盖常规审批与离线捷径两条完整职业线、提前取资料、非法提前入职、成果去重及离职保留。`interaction_test.gd` 通过场景中实际最近目标选择与对话选项完成三轮、实习、无 HC、换组、产出、答辩、正式转正，并检查走动中断。首次集成发现两位人物与隔板重叠，已调整到过道并复验通过。剧情不暂停物理、不锁移动或攻击。

## Phase 05

第二家公司一轮面试与入职、帮助/拒绝/结伴交涉/主动冲突四种现场分支已接入。帮助需操作终端，拒绝会让阿乐前往交接工位，交涉需等同伴到老板身边，冲突中断工作且不冒充交付。1 星明确警告、2 星关闭职业机会、3 星永久决裂；按公司和动作 ID 去重，警告前已发射物不计作警告后的升级。`consequence_test.gd` 通过独立入职、拒绝、交涉、帮助、连锁去重、公司隔离、决裂阻止返聘；全套回归通过。两家公司都关闭后，界面明确提示有限内容，可继续自由活动。

## Phase 06

七天发薪周期，1 现实秒=3 游戏分钟，在职每游戏分钟计 20 分（即每天 288 元）；按日历在职时间累计，不做考勤与任务绩效。应付按公司保留，余额和发薪记录可查看。公交站可休息到傍晚或快进一天。小夏、许姐、阿乐下班后通过碰撞网格寻路去公共区；离职仍可交谈，关系事件一次记账，拒绝造假不受好感覆盖。`payroll_test.gd` 与 `schedule_test.gd` 通过多期工资及三位人物实际到达公共区验证。

## Phase 07

完整版本化 JSON 存档接入 F5 保存、F9 继续、启动自动继续，以及职业/冲突/发薪结果延迟合并保存。使用校验摘要、临时文件验证后替换、有效上一份备份；损坏主档不会覆盖有效备份，恢复时保留原文件。物品每个稳定 ID 只有一个归属，非法双手持与大件入包被拒绝。`save_test.gd` 验证职业、工资、警告、NPC 倒地、手持/背包、投出后死亡读档、损坏档和备份、非法存档整体拒绝及结算不重复。测试使用独立临时文件，不覆盖玩家存档。
