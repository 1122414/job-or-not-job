# C3a 社区书屋与多解活动验收

日期：2026-09-29。源码基线2173965，中文实施提交20cf272，未push。本阶段为公共场所和事件工程交付；完整G01—G06、64km²都市圈/16km²密集城区、正式视听和独立玩家验收继续开放。

## 交付内容

榕树街原封闭楼体改为可进入的社区书屋，包含入口、书架、阅览桌、播放屏和公告；M地图可导航。书屋9—20时开放，居民沿公共路网自然进入阅览区，闭馆时离开，出口始终可用。公众人物复用原12人，不另外生成冒充赴约的角色。

街区记忆分享允许三种处理：先在播放台诊断并启用本地图册；在阅览桌准备纸本并围桌共读；去社区花园展开图画展。三条路线改变现场准备对象、居民目的地和展示内容。至少两位受邀居民实际到场、清醒且没有恐惧，玩家在现场，才累计18秒分享；离场、攻击引起避险、闭馆、地图暂停均不能继续计作参与。世界内三幅原创SVG插画实际显示在纸本、投影屏和展板，故事另有可读字幕；素材属于虚构街区插画，不是历史照片或最终写实素材。

活动进行中可保存并继续，v15校验准备状态、完成结果、进度和唯一参与者；v1—v14显式初始化新增活动。实际参加者会记得结果；与小夏/阿乐“聊聊近况”后可谈起书屋，关系记忆只加一次，原有私人邀约仍可用。活动不替玩家入职、不代替职业交付、不增加工资或强制消费。

## 边界与下一步

这是首个公共场所/三方案事件。受邀者固定为三位已有居民，内容仍只有一场短分享；普通阅览仍为站立停留，精细坐读、翻页、布展动作、正式对白和空间声景未完成。人物、道具与建筑仍有明显原型感；不能把三种准备路径等同于完整开放世界自由度，也不能把18秒事件等同于半小时自由游玩已经成立。

旧公共居民的死亡现场处置仍开放，未通过复活/隐藏身体绕过交通问题。本阶段不实现完整城市服务、动态事件网络、跨区卸载、八区扩建、正式车模/驾驶品质或双画质长期性能。接续重点为更多可参与的公共场所、持续事件后果和公共现场处置；整城与正式视听目标保持原范围。

复用并更新经验：[活动目标优先级和实际参与](experience/patterns/activity-priority.md)、[存档扩充](experience/patterns/save-content-expansion.md)。
