# 原创城区轿车运行资产

由 `tools/prepare_city_car.gd` 离线制作，复用 `tools/prepare_city_bus.gd` 的曲面、管状几何与合批辅助方法。两个制作源和六份运行网格的 SHA-256 均记录在 `production.json`；没有第三方汽车源、付费资产或新增依赖。人物沿用现有角色资产及其许可记录。

车身、座舱、玻璃、前灯、尾灯及可复用轮组为独立 ArrayMesh，较高面数部件包含自动 LOD。单车烘焙几何 78,040 三角形（轮组四份；司机、运行时方向盘和灯光另计）。轮拱内盖有相隔5毫米的内外面，避免从外侧因背面剔除看穿。Y 向上、-Z 为前方，轮组绕 X 轴滚动，前轴绕 Y 转向。原 `CityCar.SEAT`、外部碰撞与平地驾驶参数保持；地板实际顶面 0.112 米。

`scripts/city_car_visual.gd` 实例化资源，按车辆复制车漆和灯罩材质，避免共享资源串色。原静态司机暂停在初始动画混合中的问题已改为明确零混合坐姿。夜间已发动汽车启用头尾灯，制动单独提高尾灯亮度；空车不点灯。

重建：`godot --headless --path . --script tools/prepare_city_car.gd`。几何、源摘要、实际衣装支撑、转向接触和昼夜恢复检查见 `tests/city_car_visual_test.gd`。运行包包含网格和制作摘要，排除制作脚本。

当前是原创整车工程资产，尚无正式精细纹理、开门上下车表演、悬架与车损；不代表写实车辆品质或持续性能验收通过。
