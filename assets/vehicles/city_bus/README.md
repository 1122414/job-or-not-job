# 101 社区公交运行资产

本车为项目原创七米社区公交几何，制作源为 `tools/prepare_city_bus.gd`，使用既有 Godot 离线生成五份按材质合批的 ArrayMesh；运行控制位于 `scripts/city_bus_visual.gd`。没有下载第三方车辆模型、贴图或引入新的资产许可。司机复用现有 MakeHuman CC0 `office.glb`，归属见 `assets/CREDITS.txt`。

重建：`/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script tools/prepare_city_bus.gd`。生成后检查 `production.json` 中源文件摘要、五份网格摘要、面数；`tests/city_bus_visual_test.gd` 检查运行资源、递减 LOD、法线和非退化三角形、原物理合同、司机接触与车门/JSON。源码和开发工具从实际发布包排除。

坐标为 Y 向上、-Z 车头。原外部碰撞 2.6×2.8×7m 不变；地面顶高 0.4m，六名乘客根位置不变。车轮中心高 0.43m，前后轴 z=-2.4/2.1；轮拱内侧 |x|=0.99m，位于乘客座位外侧。左侧塞拉门服务现有内环站台，门扇先外移再分开；门关闭完成后车辆才能驶离，存档恢复由停站状态重建门姿态。门是视听表现，不新增自由步行入舱通路。

司机是已有交通车辆相同层级的显示人物，没有新增居民身份、交谈或职业流程。三盏舱灯和两盏前照灯仅在夜间开启；不能据此声称已完成正式照明/混音或驾驶服务模拟。静态/动态烘焙几何预算80K三角形（司机作为角色另计）；车辆之外的完整场景和持续FPS另验。车身材料仍为基本PBR颜色，尚缺细化纹理、正式制造细节与最终艺术签收。


座椅按已有乘客根坐标适配实际衣装：座垫后段顶高约0.79m、前缘连续下弯，后背独立退让；未将人物或物理根抬离原地板。轮罩内盖与橡胶轮拱保持距离，避免共面闪烁。完整车辆含方向盘和地板74,160三角形，司机单独计入人物预算；当前实际生成95条LOD记录。数值与画面均需按同一生成摘要验收，不证明持续正常帧率。
