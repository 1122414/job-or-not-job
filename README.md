# 今天不上班

Godot 4.7.1 / GDScript / Compatibility。第三人称连续小街区职场沙盒 MVP：两家公司、完整换组转正、人情事件、自由动手、物品背包、死亡复活、工资与存档。角色使用有服装、贴图和骨骼的正常人体模型，HUD 参考 GTA 式圆形地图、生命条、冲突星级与近肩镜头。

## 直接试玩（macOS）

解压 `build/今天不上班-macOS-0.3.0.zip`，打开 `今天不上班-0.3.0.app`。这是本地开发构建，使用同版本 Godot 运行时，体积较大；采用临时签名，未做 Apple 公证。已在当前 Apple M5 Pro 上独立运行验证。其他设备/平台未验证。

## 从源码运行

安装 Godot **4.7.1**，导入 `project.godot`，按 F5；或 `godot --path .`。资产已在仓库中，无运行时下载、账号或联网要求。

- 全部检查：`sh tools/check.sh`（30 项测试，导入、启动、回归日志在 `logs/`）。
- 打包：`sh tools/package_macos.sh`。默认引擎在 `/Applications/Godot.app/Contents/MacOS/Godot`，可用 `GODOT_BIN` 覆盖；需 macOS 自带 codesign/ditto 与 Python 3。
- 性能短测：`godot --path . --script tests/performance.gd`，输出 `build/performance.json`。
- 无玩家存档的视觉检查：`godot --path . --script tools/visual_preview.gd`。

| 移动 / 跑 / 跳 | WASD / Shift / Space |

默认镜头震动可关闭，鼠标灵敏度可调。灰色星表示当前公司未升级冲突；黄色星表示该公司的后果，不是警方通缉。小地图北朝上，人物箭头随朝向旋转。

## 首次路线提示

开局就能进入任一家。规程科技的 HR → 技术主管 → 老板完成三轮短面试；实习入职分配右侧第一排工位，HR 和主管会主动走来；在资料柜获取资料后，回个人工位整理并预览，再在同事与演示终端间发现要求，也可使用离线演示捷径。考核通过但无 HC 后，找二组负责人、处理备用投影仪，再找老板答辩，确实转为正式员工。

可随时离开或主动离职，前往自己人网络，参与阿乐的加班交接事件。帮助、拒绝、结伴交涉和冲突有不同现场结果；结伴交涉需要同伴实际到老板身边。下班后可到公交站和路边摊找重要同事。公交站支持快进。桌椅和打印机留在现场，小件可随身携带。

一次冲突先警告；警告后再次主动升级关闭机会；进一步升级永久决裂，按公司分别记录。连锁物理命中不重复升级。NPC 轻击先踉跄，重击或低生命时倒地，非致命倒地会恢复，死亡者不复活，现场平静30秒后关键岗位由入口到岗的新人接替；玩家倒地 2 秒后附近复活，保护 5 秒，装备不丢，公司后果不清。

时间为现实 1 秒推进 0.5 游戏分钟；场景对话为正常时钟的0.2倍，背包/任务/帮助/暂停面板停止世界；七天一个发薪周期；在职每游戏分钟累计 20 分，不要求完成任务，离职前应得工资仍保留。暂无消费系统。

## 存档

启动自动继续；关键职业/冲突/发薪结果会保存。位置和持物的主动保存用 F5，退出推荐菜单“保存并退出”。单存档位于 macOS `~/Library/Application Support/Godot/app_userdata/今天不上班/neighborhood.json`。`.bak` 是上一份有效备份；主档损坏时尝试备份，保留损坏文件，不直接清档。测试不覆盖玩家存档。重新试玩请使用Esc菜单的新游戏入口，会先保留当前进度；菜单可恢复上次重开前的存档。备份失败不会重开，保存失败明确提示。
