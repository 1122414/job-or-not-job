# 今天不上班

Godot 4.7.1 / GDScript / Compatibility。第三人称连续小街区职场沙盒 MVP：两家公司、完整换组转正、人情事件、自由动手、物品背包、救助返岗、工资与存档。角色使用有服装、贴图和骨骼的正常人体模型，HUD 参考 GTA 式圆形地图、生命条、冲突星级与近肩镜头。

## 最新品质审查与长期规划

2026-09-29已按用户确认的“GTA VI展示水准、高密度写实世界、预算后定”完成[当前差距审查](docs/2026-09-29_GTA6品质差距全面审查.md)与[完整开发路线](docs/2026-09-29_GTA6级品质开发纲要与实施路线.md)。本轮仅审查和规划，游戏代码未变；正式资产与连续体验进入长期目标的核心关卡，不能继续用功能回归代替品质验收。当前下载包仍为9月22日构建，未包含9月23日源码中的面试修改。

## 直接试玩（macOS）

解压 `build/今天不上班-macOS-0.5.0.zip`，打开 `今天不上班-0.5.0.app`。这是本地开发构建，使用同版本 Godot 运行时，体积较大；采用临时签名，未做 Apple 公证。已在当前 Apple M5 Pro 上独立运行验证。其他设备/平台未验证。

## 从源码运行

安装 Godot **4.7.1**，导入 `project.godot`，按 F5；或 `godot --path .`。资产已在仓库中，无运行时下载、账号或联网要求。

- 全部检查：`sh tools/check.sh`（41 项测试，导入、启动、回归日志在 `logs/`）。
- 打包：`sh tools/package_macos.sh`。默认引擎在 `/Applications/Godot.app/Contents/MacOS/Godot`，可用 `GODOT_BIN` 覆盖；需 macOS 自带 codesign/ditto 与 Python 3。
- 性能短测：`godot --path . --script tests/performance.gd`，输出 `build/performance.json`。
- 无玩家存档的视觉检查：`godot --path . --script tools/visual_preview.gd`。

## 首次路线提示

开局自由选择公司，A三轮、B一轮面试。面试结束先等次日10:00通知，N查看、追问或回复；公交站可预览下一安排并休息。接受条件后约次日09:00报到，迟到可在N中改约。前台核对并领取工牌后才计薪、分配工位；带领途中可暂停或自行探索。第一次使用电脑遇到账号问题时，目标会提示回前台核对。

A工作在电脑阅读正式说明、未确认草稿与离线说明，选择依据和运行方式，检查错误再修改。预览通过不等于交付，仍需去现场展示。B交接核对请求人、内容和真实截止时间，再实际发送或准备协商材料。O查看自己实际听过的约定；后续选择与成果会保留。

可随时离开或主动离职，前往自己人网络，参与阿乐的加班交接事件。帮助、拒绝、结伴交涉和冲突有不同现场结果；结伴交涉需要同伴实际到老板身边。下班后可到公交站和路边摊找重要同事。公交站支持快进。桌椅和打印机留在现场，小件可随身携带。

一次冲突先警告；警告后再次主动升级关闭机会；进一步升级永久决裂，按公司分别记录。连锁物理命中不重复升级。NPC 轻击先踉跄，重击或低生命时倒地，普通徒手最多打昏，救助人员会沿路搬运离场，次日09:00原人返岗且记得受伤经历，死亡者不复活，现场平静30秒后关键岗位由入口到岗的新人接替；玩家倒地 2 秒后附近复活，保护 5 秒，装备不丢，公司后果不清。

时间为现实 1 秒推进 0.5 游戏分钟；场景对话为正常时钟的0.2倍，背包/任务/帮助/暂停面板停止世界；七天一个发薪周期；在职每游戏分钟累计 20 分，不要求完成任务，离职前应得工资仍保留。暂无消费系统。

## 存档

启动自动继续；关键职业/冲突/发薪结果会保存。位置和持物的主动保存用 F5，退出推荐菜单“保存并退出”。0.5.0独立存档位于 macOS `~/Library/Application Support/Godot/app_userdata/今天不上班-0.5.0/neighborhood.json`。首次启动会读取并复制旧目录“今天不上班”内的有效进度，不改写旧文件；已有新版档时不重复导入。`.bak` 是上一份有效备份；主档损坏时尝试备份，保留损坏文件，不直接清档。测试不覆盖玩家存档。重新试玩请使用Esc菜单的新游戏入口，会先保留当前进度；菜单可恢复上次重开前的存档。备份失败不会重开，保存失败明确提示。
